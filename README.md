## Запуск

Самый простой способ — открыть `index.html` в браузере (все ресурсы лежат рядом в `assets/`).

Если нужен локальный веб-сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000/ (или http://localhost:8000/index.html).

## Что внутри

- `index.html` — исходная разметка Tilda с локальными ссылками на ресурсы.
- `assets/` — CSS, JS, шрифты и изображения (включая favicon), скачанные с CDN Tilda и Google Fonts.

Оптимизация изображений Tilda отключена (`data-tilda-imgoptimoff="yes"`), чтобы страница полностью работала офлайн и не зависела от CDN. Визуально используются те же оригинальные изображения.

- Формы и всплывающие окна работают на клиенте; фактическая отправка заявок зависит от сервисов Tilda.
